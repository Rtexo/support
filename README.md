# Rtexo Support

Public support and feedback tracker for Rtexo products.

## SOQL Data Source for Salesforce

The current product is a JetBrains IDE plugin that adds Salesforce as a data source in **IntelliJ IDEA Ultimate** and **DataGrip**. It uses the standard JetBrains Database Tools workflow, authenticates through the Salesforce CLI, runs SOQL queries, and provides Salesforce object and field metadata for browsing.

- **Install:** [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34615)
- **Product website and overview:** [rtexo.com](https://rtexo.com/)
- **Source code and technical documentation:** [Rtexo/jb-sf-datasource](https://github.com/Rtexo/jb-sf-datasource)
- **Privacy policy:** [Plugin privacy policy](https://rtexo.com/plugins/jb-sf-datasource/privacy)

## Get help or report a problem

[Open an issue](https://github.com/Rtexo/support/issues) to report a reproducible problem or suggest an improvement. Choose the matching form so maintainers receive the details needed to investigate.

For a bug report, include the plugin version, IDE and version, operating system, Salesforce CLI version, steps to reproduce, and expected and actual behavior. Use a small representative query only when it helps reproduce the problem.

For a feature request, describe the task you are trying to complete, the current limitation, and the outcome that would help.

## Keep reports safe to share

The plugin connects from your IDE to Salesforce using your local Salesforce CLI authentication. Rtexo does not proxy plugin queries through a Rtexo backend. Public issues are visible to everyone, so remove credentials and sensitive organization information before posting.

Do not include access tokens, refresh tokens, passwords, session IDs, auth URLs, private keys, customer or employee data, or unredacted logs. Redact Salesforce record IDs, organization identifiers, hostnames, usernames, and any query values that could reveal private business information. If a report contains sensitive details, do not post them publicly; contact [support@rtexo.com](mailto:support@rtexo.com) to discuss a safe way to share them.
